Wo Ihre Daten bleiben

Alle Einträge, die Sie hier erfassen, bleiben in diesem Browser (im Browserspeicher OPFS/IndexedDB):

  • Nichts wird hochgeladen — kein Cloud-Dienst, keine Analyse, keine Nutzungsstatistik.
  • Umgekehrt gibt es keine Synchronisierung zwischen Browsern oder Geräten: Jeder Browser und jedes Gerät hält seine eigene Kopie.
  • Gelöscht werden die Daten durch die Browser-Option „Websitedaten löschen“, im privaten Modus verschwinden Einträge mit dem Fenster — und ein Wechsel des Browsers oder Geräts ist ein Neuanfang.

Daten sichern

Über Einstellungen › JSON-Export speichern Sie Ihre Einträge als Datei — regelmäßig exportieren ist die einzige Sicherung. Über den JSON-Import spielen Sie sie später wieder ein.

Verbleibende Risiken

Der Browserspeicher ist von der App her nicht verschlüsselt: Wer (physisch oder per Schadsoftware) Ihr Browserprofil ausliest, kann die Einträge sehen. Zusammen mit der Beta-Phase gilt: Nur Daten eintragen, deren Verlust oder Offenlegung Sie verschmerzen können — Einzelheiten im README (englisch).

Zur App-Demo

English

This app is in beta — do not rely on the data. Data loss is not ruled out. For serious use, install the Android app from the releases page (an iOS build does not exist yet). The demo is built from the current development state, so it shows the upcoming release rather than the latest published one.

The web demo shows the app on the web iteration target (details in the GitHub repository): you enter cycle data by hand — the app computes and plots the curve, it never decides anything. Knowing the method (book or course) is a prerequisite for reliable interpretation.

Where your data stays

Every entry you make here stays in this browser (browser-local storage, OPFS/IndexedDB):

  • Nothing is uploaded — no cloud service, no analytics, no usage statistics.
  • Conversely, there is no sync between browsers or devices: every browser and every device holds its own copy.
  • The browser's “clear site data” wipes the entries, private windows discard them on close, and switching browser or device is a fresh start.

Getting data out

Einstellungen (settings) › JSON-Export saves your entries to a file; the JSON-Import brings them back later.

Residual risks

The browser storage is not encrypted by the app: anything that reads your browser profile can read the entries. Combined with the beta status: only enter data whose loss or exposure you can live with — details in the README.
